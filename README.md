# Nextexam - Online Examination and Academic Management System

Nextexam is a Java-based web application developed for the SE1020 Object Oriented Programming project. The system provides role-based access for Admin, Lecturer, and Student users.

## Main Features

- Role-based login
- Admin dashboard
- Lecturer dashboard
- Student dashboard
- Student management
- Lecturer management
- Module management
- Exam management
- Question bank
- Student exam attempts
- Result management
- Notices
- Feedback
- Document upload and verification
- Dashboard analytics

## Technologies Used

- Java
- JSP
- Servlets
- HTML
- CSS
- JavaScript
- File Handling
- IntelliJ IDEA
- Apache Tomcat
- GitHub

## How to Run

1. Clone the repository.
2. Open the project using IntelliJ IDEA.
3. Configure Apache Tomcat.
4. Build the Maven project.
5. Run the application.
6. Open the system in the browser.

## Academic Note

This project demonstrates Object-Oriented Programming concepts such as encapsulation, inheritance, polymorphism, abstraction, and file handling.
